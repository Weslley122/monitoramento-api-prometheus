O painel não carregou

Este app precisa ser aberto pelo Vite. Na pasta do projeto, rode npm install e depois npm run dev, e acesse o endereço que aparecer (normalmente http://localhost:5173).

Abrir o index.html direto (duplo clique ou Live Server) deixa a tela em branco, porque o navegador não entende os arquivos .jsx sem o Vite.
